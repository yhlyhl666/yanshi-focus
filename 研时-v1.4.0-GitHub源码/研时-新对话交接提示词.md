# 研时 PC 版开发交接提示词

你现在接手一个已经完成基础版本的 Windows 桌面考研专注计时器项目，请在保留现有功能和数据的前提下继续开发，不要从零重写。

## 项目目标

“研时”是类似番茄 Todo 的考研学习计时软件，面向考研用户。核心功能包括：番茄计时、科目选择、学习任务、学习统计、各科总时长、手动补录/减少时长、考研日期倒计时、本地数据保存和 Windows 桌面安装包。

当前用户最看重的方向：

1. 首页有“今日状态”和“精力负荷提示”。
2. 有电子宠物/卡通模型，并且未来希望支持“根据用户照片生成本人卡通形象”。
3. 当前先完成基础功能，不要急着接照片生成 API。
4. 界面不要像普通 AI 生成的卡片堆，要柔和、有陪伴感、交互自然。

## 已完成的功能

### 计时

- 专注/休息模式
- 25、45、60、90 分钟快捷时长
- 开始、暂停、重置、跳过
- 沉浸专注模式
- 可关联科目和任务
- 计时状态本地恢复
- 完成专注后写入 sessions

### 任务

- 新建、完成/取消完成、删除、撤销删除
- 任务关联科目
- 预计番茄钟数量
- 每个任务新增预计精力消耗 `1–5`
- 新建任务弹窗中可以选择精力消耗

### 今日状态和精力负荷

当前实现方式：

- 每日精力容量固定为 `10`
- 统计所有未完成任务的 energy 总和
- 当前状态阈值：
  - 0 项待办：`清空啦`
  - 1–3：`轻负荷`
  - 4–6：`舒适区`
  - 7–9：`偏满`
  - 10 及以上：`超载`
- 首页右侧显示：
  - 状态标题
  - 陪伴式提示文案
  - 精力负荷进度条
  - 未完成任务数量
  - “调整任务”按钮

当前示例任务的负荷是 `7 / 10`，显示“偏满”。

相关组件在 `src/App.jsx`：

- `PetStatusPanel`
- `PetIllustration`
- `getTaskEnergy`
- `getEnergyStatus`
- `DAILY_ENERGY_CAPACITY`

### 电子宠物

- 当前是独立的内置 SVG 卡通形象，不依赖外部图片。
- 宠物会根据状态改变配色，并有非常轻微的上下浮动动画。
- 未来要支持照片生成时，只需要替换 `PetIllustration` 内部内容或增加头像来源字段，不要破坏状态逻辑。
- 不要直接复制参考软件的插画或代码。

### 统计

- 日/周/月统计
- 饼状图和柱状图
- 各科累计总时长
- 手动补录专注时长
- 手动减少已有专注时长
- 修改已有记录时长
- 删除记录
- 修改会同步到各科分布和图表

### 设置

- 专注时长、短休息、每日目标
- 自定义考研日期
- 28 届预计日期默认是 `2027-12-25`
- 自动开始休息
- 严格模式

## 最近修复的问题

### 计时器数字黑点

原来计时器使用 `Cascadia Mono`，该字体的数字 `0` 是点状 0，所以 `00` 中间会出现黑点。现在已增加 `--font-timer`，计时器改用 Arial / Microsoft YaHei UI，不再显示黑点。

不要把普通统计数字的字体改坏；目前只针对计时器和沉浸模式计时数字调整。

### 背景和圆角

最近已调整 `tokens.css`：

- 背景改成更柔和的暖米白
- 卡片背景更接近奶油白
- `radius-xs / sm / md` 整体增大
- 卡片增加轻微阴影

## 用户偏好和沟通方式

- 用户不喜欢解释过多的设计系统、token 或审计过程。
- 用户更想直接看到实际效果、截图和安装包。
- 用户希望界面看起来不像“AI 生成的简单卡片”。
- 做 UI 改动时先给结果，再用很短的话说明改了什么。
- 不要擅自扩展到复杂功能；尤其是照片生成卡通形象，先保持为下一阶段。

## 建议的下一步

优先级从高到低：

1. 让用户实际安装 1.2.0，确认暖米白背景、圆角卡片、计时数字和电子宠物是否满意。
2. 如果用户确认基础视觉方向，再增加“今日状态”的手动状态校准，例如今天精力低/正常/充足，但不要覆盖自动负荷判断。
3. 为任务增加编辑精力值的入口，避免只能在新建任务时设置。
4. 再设计照片上传和卡通形象生成接口，先预留头像字段和替换组件，不要在没有明确 API/服务选择时接入第三方服务。
5. 如果继续做移动端，沿用今日状态、精力负荷和电子宠物的逻辑，但单独设计移动布局。

## 建议调用的技能

- `ui-ux-pro-max`：继续做界面、颜色、卡片和交互设计

- `playwright` 或桌面渲染检查脚本：验证窗口尺寸、交互和无横向滚动
